Salt Master has been installed successfully.

Check the workload:

  kubectl -n {{ .Values.namespace }} get pods -l app=salt-master

Check the Salt Master logs:

  kubectl -n {{ .Values.namespace }} logs deployment/salt-master \
    --container salt-master

List known minion keys:

  kubectl -n {{ .Values.namespace }} exec deployment/salt-master \
    --container salt-master \
    -- salt-key -L

{{- if .Values.agent.trustedMinions.enabled }}

Minion trust is managed declaratively by salt-key-operator.

Create a SaltMinionKey in namespace "{{ .Values.namespace }}":

  apiVersion: salt.saltstack.io/v1alpha1
  kind: SaltMinionKey
  metadata:
    name: <minion-id>
    namespace: {{ .Values.namespace }}
  spec:
    minionId: <minion-id>
    publicKey: |
      -----BEGIN PUBLIC KEY-----
      ...
      -----END PUBLIC KEY-----

Trusted-minions ConfigMap:

  {{ .Values.agent.trustedMinions.configMapName }}

ConfigMap propagation through kubelet can take approximately one minute,
plus the sidecar polling interval of
{{ .Values.agent.trustedMinions.syncIntervalSeconds }} seconds.

{{- else }}

salt-key-operator integration is disabled.

Accept a pending minion manually:

  kubectl -n {{ .Values.namespace }} exec deployment/salt-master \
    --container salt-master \
    -- salt-key -a '<minion-id>'

Warning: manually accepted minion keys are stored in the pod's writable
temporary PKI volume and do not survive a Salt Master pod replacement.
Enable agent.trustedMinions.enabled for persistent declarative trust.

{{- end }}
