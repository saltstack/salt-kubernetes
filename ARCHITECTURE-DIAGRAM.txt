COMMUNICATION FLOW
═════════════════════════════════════════════════════════════════════════════

1. MINION → MASTER (Initial Connection)
   ────────────────────────────────────
   salt-minion (salt namespace) → salt-master (salt-master namespace)
   └─ Connects to master via SALT_MASTER env var
   └─ Uses ZeroMQ on ports 4505 (publish) & 4506 (request/return)

2. MASTER → MINION (Command Execution)
   ──────────────────────────────────────
   salt-master (salt-master namespace) → salt-minion (salt namespace)
   └─ Executes salt commands: salt '*' cmd.run 'hostname'
   └─ Minion responds with results

3. KEY MANAGEMENT
   ───────────────
   a) Key Generation (Pre-install Job)
      salt-minion-keygen job → Creates secret with minion.pem, minion.pub

   b) Key Acceptance (Operator)
      salt-key-operator → Watches SaltMinionKey CRD
      → Writes to salt-master-trusted-minions ConfigMap
      → trusted-minions-sync copies to /etc/salt/pki/master/minions

4. HEALTH MONITORING
   ──────────────────
   Kubernetes Kubelet → Runs probes every 30s (liveness), 30s (readiness)
   └─ If probe fails 3 times → Pod is restarted automatically

RBAC SETUP
═════════════════════════════════════════════════════════════════════════════

salt-master namespace:
├─ ServiceAccount: salt-master
│  └─ No auto-token (disabled for security)
│
├─ ServiceAccount: salt-key-operator
│  └─ Auto-token enabled (needed for API access)
│  └─ Role: Can create/update/delete ConfigMaps
│
└─ ServiceAccount: salt-minion-keygen-job
   └─ Can create Secrets

salt namespace:
└─ ServiceAccount: salt-minion
   └─ Auto-token enabled (needed for Kubernetes API module)
   └─ ClusterRole: Full cluster admin (can be restricted)

STORAGE LAYOUT
═════════════════════════════════════════════════════════════════════════════

Secret: salt-master-master-keys (in salt-master namespace)
├─ master.pem (private key)
└─ master.pub (public key)

Secret: salt-minion-keys (in salt namespace)
├─ minion.pem (private key)
└─ minion.pub (public key)

ConfigMap: salt-master-trusted-minions (in salt-master namespace)
├─ <minion-id>: <public-key-pem>
└─ <minion-id>: <public-key-pem>

PersistentVolumeClaim: salt-minion-vcf-pki (in salt namespace, optional)
└─ Persistent storage for minion keys across pod restarts


REPLICAS & SCALE
═════════════════════════════════════════════════════════════════════════════

Current Configuration:
├─ salt-master: 1 replica (can be scaled to 3+ for HA)
├─ salt-key-operator: 1 replica
├─ salt-minion (K8s): 1 replica
└─ salt-minion-vcf: 1 replica

For High Availability:
├─ salt-master: 3+ replicas (StatefulSet with shared keypair)
├─ salt-key-operator: 2+ replicas (with leader election)
├─ salt-minion (K8s): 1-3 replicas
└─ salt-minion-vcf: 1 replica (StatefulSet recommended)


NETWORK POLICY REQUIREMENTS
═════════════════════════════════════════════════════════════════════════════

If using NetworkPolicy, allow:

From salt-minion → salt-master:
  └─ Protocol: TCP
     Port: 4505 (publish) and 4506 (request/return)

From salt-minion → Kubernetes API:
  └─ Protocol: TCP
     Port: 443 (if using saltext.kubernetes)

From salt-minion → Vault (if enabled):
  └─ Protocol: TCP
     Port: 8200 (Vault API)
